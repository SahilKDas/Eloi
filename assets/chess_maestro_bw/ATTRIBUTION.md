# Maestro BW chess pieces

The twelve PNG files in this directory are 512-by-512 transparent raster
conversions of the
`chess_maestro_bw` piece set from
[Kadagaden/chess-pieces](https://github.com/Kadagaden/chess-pieces/tree/master/chess_maestro_bw).

- Creator and source repository: Kadagaden, `chess-pieces`
- Upstream note: a black-and-white version of the Lichess Maestro set
- License: [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)
- Changes to the artwork: converted from SVG to PNG without visual alterations

Eloi's board, highlights, panels, buttons, labels, and other interface graphics
are generated in code. Only these twelve piece PNGs are used from the upstream
asset repository.
